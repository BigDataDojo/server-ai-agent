# 用語集

分からない言葉が出てきたら、ここを見る。載っていない言葉は PR で追加する。

| 用語 | 意味 |
| --- | --- |
| 鯖缶 | サーバー管理者。研究室のサーバー群を整備・運用する人 |
| 属人化 | 特定の人しかできない状態。その人がいなくなると誰も対応できない |
| フロンティアモデル | Claude、GPT などの最先端モデル。API 経由で使う |
| ローカルLLM | 研究室の GPU サーバーで動かす公開モデル。データが外に出ない |
| エージェント | モデルが自分で判断してツール（コマンド、API）を呼び、結果を見てまた判断する仕組み |
| ルーティング | 問い合わせを内容に応じて適切なエージェントに振り分けること |
| RAG | ドキュメントから関連箇所を検索し、それを元に回答を生成する方式 |
| MCP | エージェントにツールを提供するための共通規格。Cloudflare などが対応している |
| Proxmox | 仮想化の管理ソフト。fsm02 で LXC を動かすのに使う |
| LXC | 軽量な仮想マシン。Proxmox 上でサービスごとに1つ作る |
| Cloudflare Tunnel | サーバー側から外向きに接続して、Cloudflare 経由で到達できるようにする仕組み |
| Cloudflare Access | 入口で本人確認する仕組み。SSH 用には Access for Infrastructure がある |
| dry-run | 実際には変更せず、何が起きるかだけ確認する実行 |
| PR | Pull Request。GitHub で変更をレビューしてもらい、取り込んでもらう依頼 |
| 決定記録 | 1つの決定について、選択肢・推奨・決定と理由をまとめた1枚の文書（`design/*/decisions/`） |
| 今週の問い | 週次 MTG で答えを出す問い。Issue として立て、担当者が決定記録の PR で答える |
