# Claude エージェント（コース B）

## 役割

サーバーに入って調査し、対処を提案し、担当者の承認を得てから実行し、作業レポートを残す。Cloudflare・Proxmox の設定変更、最新情報の収集、複数ログの突き合わせもここが担う。

## 目標

12月までに「提案のみ」（自動化レベル 1）でテスト運用を始める。開発は Sage が進め、コース B の学生は設計を読んで理解し、質問し、穴を見つけ、「要確認」の項目を実際に試して確かめる。

## 現在の構成

まだこの設計書には書いていない。キックオフ前の検討内容（Agent SDK、MCP、承認フック、監査ログなど）は [archive/overview.md](../../archive/overview.md) にあり、採用が決まったものから決定記録にしてここへ移す。
