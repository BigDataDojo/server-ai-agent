# ビジョン・スコープ

## 目的

サーバーの日常運用（監視・記録・更新・問い合わせ対応）を AI エージェントに任せ、
人間は **判断と承認** に集中できるようにする。

## 想定する対象

- 自宅サーバー / 研究室サーバー / 小規模な VPS 群（数台〜数十台）
- OS は Linux を想定（ディストリビューションは未定 → [open-questions](open-questions.md)）

## スコープ（やること）

1. **記録**：エージェントの全行動と、システムの状態変化を残す
2. **保守**：カーネル・パッケージ・モジュールの更新を計画し、承認後に実行する
3. **対話**：自然言語での質問に、実際のサーバー状態を調べて答える
4. **一次対応**：障害時に情報を集め、原因候補と対処案を提示する

## 非スコープ（当面やらないこと）

- 承認なしでの破壊的操作（削除・再起動・設定変更）
- セキュリティインシデントの自動封じ込め（検知と通知まで）
- 本番クラスタ全体のオーケストレーション（Kubernetes 等の代替にはしない）

## 成功の目安（仮）

- 毎朝「昨日何が起きたか」の要約が届く
- アップデートが「計画 → 承認 → 実行 → 検証」の流れで回る
- 障害時に、人間が最初の 10 分でやっていた調査をエージェントが代わりにやっている
