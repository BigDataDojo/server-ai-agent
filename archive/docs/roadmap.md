# ロードマップ（たたき台）

段階的に「任せる範囲」を広げていく。各フェーズで実際に使ってみて、次へ進むか判断する。

## Phase 0：構想整理 ← いまここ
- [ ] やりたいことの洗い出し（このリポジトリ）
- [ ] [open-questions](open-questions.md) の主要項目を決める
- [ ] 対象サーバー・ハードウェア構成の確定

## Phase 1：観察者（読み取り専用）
- [ ] ローカル LLM の推論環境を構築
- [ ] 読み取り専用ツール群を定義
- [ ] 質問応答（Q&A）が動く
- [ ] 監査ログの記録が動く
- [ ] 日次ログ要約レポート

## Phase 2：助言者（提案まで）
- [ ] API モデルとのルーティング実装
- [ ] アップデートの検出・分析・計画作成
- [ ] トラブル時の一次切り分けと対処案の提示
- [ ] 通知（チャット等）

## Phase 3：実行者（承認制）
- [ ] 承認フローの実装
- [ ] スナップショット / ロールバック機構
- [ ] 承認後のアップデート実行と事後検証

## Phase 4：自律運用（限定的）
- [ ] 低リスク操作の自動実行
- [ ] 知識ベースの自動蓄積（ポストモーテム）
- [ ] 複数サーバー対応
