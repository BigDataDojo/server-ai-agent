# ユースケース：実行ログの記録

## 2 種類のログ

### 1. エージェント自身の行動ログ（監査ログ）
エージェントが「何を見て、何を考え、何を実行し、どうなったか」をすべて残す。

記録したい項目（案）：
- タイムスタンプ、セッション ID、トリガー（人間の指示 / 定期実行 / アラート）
- 使用モデル（ローカル or API、モデル名）とトークン数・コスト
- 実行したコマンド、終了コード、出力（長い場合は要約 + 原本へのリンク）
- 承認の有無と承認者
- 変更前後の状態（ロールバック用）

### 2. システムログの収集・要約
- journald / syslog / アプリケーションログを読み、定期的に要約
- 異常の兆候（エラー急増、OOM、ディスク逼迫、認証失敗の多発）を検知して通知

## アイデア

- 日次レポート：「昨日の主な出来事」「注意が必要なこと」「エージェントがやったこと」
- 改ざん防止：監査ログは追記専用、ハッシュチェーン化、または別サーバーへ転送
- 保存期間とローテーションのルール
